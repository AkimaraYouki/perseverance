C-WANG 브링업 — 원스톱 (2026-10-12)
================================================

[1] 로봇 전원
  1. 젯슨 전원 ON  →  2. 모터 배터리 연결  (반드시 젯슨 먼저)
  3. 1분쯤 기다림: gen2-bench (센서·모터 모니터·LCD·카메라) 와 gen2-balance (균형 노드, 해제 상태) 가 자동으로 뜸
     LCD 에 IMU·모터 4 개·라이다가 초록이면 준비 끝
  4. 게임패드 (Xbox) 블루투스 연결

[2] 데스크톱 — 한 번에
  cw up
     = 로봇 확인 → SLAM 켬 → 패드 (joy_node + pad_teleop) → RViz → 상태판  (각각 새 터미널 탭)
  cw check          지금 상태만 보기 (로봇 연결, 서비스, SLAM, 비전, 패드, RViz)

[3] 패드 조종
  START          일어서기 → 똑바르면 자동 균형
  BACK           천천히 앉기 → 해제
  LB + RB 0.5초  비상 해제 (모터 0 A — 로봇이 떨어짐, 손으로 받칠 것)
  왼스틱 위아래   앞뒤 (최대 0.7 m/s)
  오른스틱 좌우   회전 (최대 2.0 rad/s)
  RT / LT        몸 높이 올리기 / 내리기
  A (누르는 동안) 정지
  B              기본 높이
  X              ArUco 추종 켜기/끄기 (대회에선 마커 금지 — 시험용)
  * 패드가 끊기면 (1초) 로봇은 스스로 멈춤 → 2초 뒤 앉아서 균형 → 30초 뒤 해제

[4] 하나씩 쓰기
  cw slam start | stop       로봇 SLAM 켜기/끄기
  cw slam reset              지도 지우고 지금 자리부터 새로
  cw slam save [이름]        지도 저장 (로봇 ~/maps/이름.pgm/.yaml)
  cw vision start | stop     로봇 비전 (ArUco 추종 + 손동작)
  cw pad                     패드만 (joy_node + pad_teleop)
  cw rviz                    RViz 만 (지도·라이다·TF·오도메트리·카메라)
  cw dash                    상태판만 (= wifi -r)
  cw ssh                     로봇 접속
  wifi                       데스크톱 Wi-Fi 신호 % (1초마다)
  wifi -r                    로봇 상태판: 전원·배터리 %·모터·센서·SSH·속도·가속·자세
  wifi -r -1                 데스크톱·로봇 신호 % 한 번만

[5] 끝낼 때
  1. 패드 BACK (앉기 → 해제)
  2. cw down        데스크톱 패드·RViz·상태판 끄기 (로봇 SLAM 은 그대로)
     cw slam save   지도 남기려면 끄기 전에
     cw slam stop   SLAM 도 끄려면
  3. 모터 배터리 분리 → 젯슨 전원 OFF

[6] 손으로 직접 (cw 없이, 터미널마다 먼저 source)
  source ~/gen2_desk/env.sh                                    ← 꼭 먼저 (없으면 FastDDS 로 붙어 지도·카메라가 깨짐)
  ros2 run joy joy_node --ros-args -p autorepeat_rate:=20.0    패드 입력
  ros2 run gen2_tools pad_teleop                               패드 → 로봇 명령 (데스크톱에서 실행)
  rviz2 -d ~/gen2_desk/gen2_desktop.rviz                       RViz (원본 gen2.rviz 는 카메라가 안 나옴)
  ros2 launch gen2_bringup slam.launch.py                      SLAM (로봇에서: cw ssh 후)

[7] 문제가 생기면
  화면에 "sequence size exceeds remaining buffer"  → source ~/gen2_desk/env.sh 안 함
  RViz 카메라 "No Image"                            → gen2_desktop.rviz 로 열었는지 (압축 토픽)
  로봇이 패드에 안 움직임                           → cw check 로 패드·pad_teleop 켜졌는지, 패드 블루투스
  pad_teleop 고친 뒤                                 → cd ~/gen2_desk && PATH=/usr/bin:/bin:$PATH colcon build --base-paths ~/perseverance/src/gen2_msgs ~/perseverance/src/gen2_tools --packages-select gen2_msgs gen2_tools  (먼저 cd ~/perseverance && git pull)
  컴퓨터 배터리 (3S 11.1 V) 가 셀 3.3 V (9.9 V) 아래  → 바로 교체 (wifi -r 의 % = 0 %)
