## 2. 고관절 — 토크 여유

평지에서 서 있을 때(속도 0, 냉각 불리) 고관절이 내는 토크는 가상일로 구한다.

```math
\tau_{\text{hold}}=\frac{Mg}{2}\cdot\frac{\partial h}{\partial\theta}\approx\frac{4.15\times9.81}{2}\times0.113\sim0.119=2.30\sim2.42\ \text{Nm}\quad[\text{계산, gains.yaml}]
```

→ **정격의 77 – 81 %**. 총중량 5.14 kg 에서 100 % 에 닿는다([CAD §3](01_cad.md#3-질량--실측-반영-export-7-2026-10-06-측정)).
- 위 식은 바퀴·다리 링크 무게까지 다리가 받는다고 본 **상한**이다. 시뮬 (export 7, 4.165 kg, 모델 오차 없음, IDLE 다리 183.7 mm 로 서 있기) 고관절 토크는 **L 1.72 / R 1.75 N·m = 정격의 58 %** [측정, 시뮬 2026-10-07].
  $\partial h/\partial\theta$ 가 θ 38 – 97.8° 전 구간 110 – 119 mm/rad 로 거의 일정해서 **서 있는 높이를 바꿔도 토크는 ±5 % 안쪽**이다 (가장 낮은 곳 θ 85 – 90°, 모터축 높이 287 – 297 mm).
- 실기 하중 시험 [측정, 로봇 2026-10-07, 타이어 없이 M = 0 (θ 45°) 유지, 손으로 몸통을 내려 하중]: 하중 구간 평균 L 3.07 A / R 2.08 A (Kt 0.5994 로 1.84 / 1.25 N·m, 합 3.09 = 시뮬 전체 체중 3.47 의 89 %), 최대 L 6.79 A (손으로 더 누른 구간, 합 6.83 N·m ≈ 체중 2 배). 40 °C.
  **좌우가 1.5 – 2 배 다르다.** CAD 무게중심은 고관절 가운데에서 오른쪽 1.3 mm (오른쪽 +1.4 %) 라 설명이 안 되고, 몸통을 싣기 전 다리만 매달고 M = 0 에 멈춰 있을 때도 0.68 / 0.46 N·m 로 1.5 배였다 → 양방향 접근 시험 (2026-10-07): 마찰 ≤ 0.03 N·m, M 20 / 40° 에서 좌우 같음 (Kt 좌우 차 아님), **왼쪽 접힘 끝 (M ≈ 0 – 5°) 에서만 +0.26 N·m** — 간섭·케이블 추정, 사용자 확인 중 (`comms/to-robot/2026-10-07_0108_desktop-hip-hold-reply.md`).
- 피크 9 Nm 는 **순간** 값이다. 다른 팀(QBMET 외골격 보고서)이 9 Nm 를 정격으로 읽고 30 분 연속으로 돌려 과열 셧다운된 사례가 있다.
- 동적 여유: 요철 흡수(0.85 m/s 로 3 cm 턱을 10 cm 안에 넘음)에 필요한 속도는 아래 정도로 한계(24.4 rad/s)보다 한참 작다.

```math
\dot h\approx0.25\ \text{m/s}\ \Rightarrow\ \dot\theta=\dot h/J\approx2.2\ \text{rad/s}
```

## 3. 바퀴 — 속도·토크 여유

```math
v_{\max}=\omega_0R=18.85\times0.06=1.13\ \text{m/s},\qquad
v_{3\,\text{km/h}}=0.833\ \text{m/s}\ \Rightarrow\ \omega=13.9\ \text{rad/s}\ (74\,\%)
```

DC 모터 토크-속도 직선에서 그 속도의 가용 토크는 다음과 같다.

```math
\tau_{\text{avail}}=\tau_s\Big(1-\frac{\omega}{\omega_0}\Big)=7\times0.26=1.8\ \text{Nm}
```

바퀴가 미끄러지지 않는 한계는 이보다 작다.

```math
\tau_{\text{fric}}=\mu\frac{Mg}{2}R=0.7\times\frac{4.0\times9.81}{2}\times0.06\approx0.82\ \text{Nm}\ \ (0.65\ \text{A})
```

→ AK45-10 은 **토크가 남는다**. 병목은 바닥 마찰이다. 예전 RL 은 바퀴 토크를 1.5 Nm 로 제한하고 실기 첫 기동을 0.5 Nm 로 자를 계획이었다.
**지금은 0.5 Nm 클램프를 쓰지 않는다** — 바퀴 축 정지 마찰만 0.45 N·m 이다 (§7.4).
시뮬에서 균형 유지에 쓴 바퀴 토크 RMS 는 0.01 – 0.10 Nm 다 [측정, CAD m4650, 마찰 넣기 전 RL 정책].

## 5. 버스·안전

- CAN 1 Mbit/s 한 버스에 4 개. 피드백 500 Hz 면 부하 56 % 로 상한이다([통신 §1.2](../software/02_communication.md#12-버스-부하--왜-500-hz-가-상한인가)).
- 2026-10-03 부터 네 개 모두 버스에 있다 (ID 1 – 4, §0). 기동할 때 CAN ID 를 자동 스캔한다 (`can_id: 0`, 0.5 s 이상 들어서 오름차순).
- 드라이브 쪽 전류 한계를 낮춘다(CubeMars 툴). 바퀴 MIT 드라이브 설정은 **전류 한계 60 A, CAN 타임아웃 0 (없음)** 이었다 → 서보에서 `l_current_max` 5 – 6 A, 타임아웃 켜기 권장 (로봇 2026-10-03).
- 기동 한계 2.0 A, 10 rad/s, 80 °C. 지령이 1 s 끊기면 드라이브가 스스로 멈춘다.
- **하드웨어 비상정지 스위치가 아직 없다 — 균형 시험 전에 필수.**

## 6. 영점

AK60-6 영점은 CAD 영점 자세($M=0$, $\theta$ 45.0°, 고관절 높이 196.5 mm)에 맞춘다. 좌우 $M$ 은 부호가 반대다. 이 자세가 IDLE 이자 자동 높이 모드의 공칭 높이다.

## 7. AK45-10 실측 (2026-10-03)

### 7.1 바퀴 들고 무부하 [측정, 로봇 Jetson `MotorTester`, 100 Hz 루프, 서보 펌웨어]

| 항목 | 값 |
|---|---|
| 속도 스케일 | 1 rad/s 명령 → ±0.996 rad/s (극쌍 14, 감속 10 맞음). 두 바퀴 모두 +전류 → +속도 (조립 후 `direction` 결정) |
| 무부하 최고 속도 | 약 17 rad/s (0.5 A 로 0.6 s, 정상 상태 아닐 수 있음) — 데이터시트 18.85 |
| **정지 마찰 / 시동 전류** | **지령 ≤ 0.40 A: 전혀 안 돎** (드라이브 보고 전류도 0), 0.50 A: 바로 돎. CubeMarsTool 그래프로는 약 0.3 A 부터 회전 → **약 0.4 – 0.5 N·m** (데이터시트 역구동 0.1 의 3 – 5 배) |
| 운동 마찰 | 5 rad/s 에서 0 A 로 놓으면 0.2 s 안에 정지 (1 kHz 정밀 측정 예정) |
| 가속 (5 rad/s 에서 전류 반전) | 0.5 A: ±315 – 330 rad/s², 1 A: ±553 – 566, 2 A: ±967 – 1118. 방향 비대칭 ≤ 3 %, 좌우 차 ≤ 10 % |
| 반전 시간 (전류 반전 → ω = 0) | 25 ms (2 A) – 44 ms (0.5 A), 샘플 100 Hz 라 ±10 ms |
| 관성 (출력축, 바퀴 포함) | $K_t\sum I/\sum a\approx$ **2.0 – 2.6 × 10⁻³ kg·m²** (로터 데이터시트 1.57 × 10⁻³) |
| 드라이브 보고 전류 | 1 A 아래에서 부정확 (음전류도 + 로 보고) — 제어에 쓰지 말 것 |

가속 세 점을 반전(마찰이 감속을 돕는 구간) 식 $a=(T+f)/I$ 로 맞추면 $I\approx2.65\times10^{-3}$, 운동 마찰 $f\approx0.22$ N·m [계산]. **사용자 실측 (CubeMars 제어, 2026-10-04): 0.5 A 미만은 안 돌고 0.5 A 이상만 돈다. 돌 때 소모 전류는 약 0.1 A** → 운동 마찰 ≈ 0.13 N·m (위 반전 가속 맞춤 0.22 보다 작다). 시뮬은 처음 정지 0.625 ± 1 % / 운동 0.13 으로 넣었고, 판정 뒤 데드밴드 0.625 / 운동 0.11 로 바꿨다 ([제어 §2](../software/04_control.md#2-바퀴-마찰--실측을-시뮬에-넣고-보상-2026-10-03)).

**판정 (로봇, 2026-10-06)**: 0.5 A 로 돌리다 지령을 0.3 / 0.2 / 0.1 A 로 낮추면 0 A 와 같은 곡선으로 0.36 s 에 멈추고 드라이브 보고 전류가 0 → **기계 마찰이 아니라 드라이브 데드밴드** (0.5 A 미만 지령을 버림). 0 A 감속 46 rad/s² 로 운동 마찰 **0.11 N·m**. 보상은 시그마-델타 ([제어 §2.3](../software/04_control.md#23-보상--가설마다-따로-그리고-둘-다-버티는-것-2026-10-04)).

고관절 AK60-6 [측정]: 위치 ±2° 명령 오차 ≤ 0.1°, 속도 ±0.5 rad/s 오차 1 %, +명령 → +각도. 전원을 껐다 켜면 임시 원점이 사라져 위치 명령 전에 원점이 필요하다.

### 7.2 MIT 와 서보 — 바퀴는 서보로

| 항목 | MIT 모드 | 서보 모드 |
|---|---|---|
| 지령 | 토크 $t_{ff}$ 를 N·m 로 바로 (AK45-10 ±8, 12 bit ≈ 0.004 N·m) | 전류 (A) → $K_t$ 를 호스트가 곱함 |
| 피드백 | 명령 한 번에 응답 한 번 (제어 주기에 맞음) | 1 – 500 Hz 정주기 업로드 (제어 주기와 어긋남) |
| 모터 안 루프 | kp·kd PD | 속도·위치 루프 + 가감속 프로파일 |
| 속도 피드백 범위 | AK45-10 ±20 rad/s (무부하 18.85 와 여유 6 %) | ±32 만 ERPM |
| UART 로 구동 | **안 됨** (§7.3) | 됨 |

제어 구조(토크 지령 200 Hz)에는 MIT 가 더 맞다. 그런데 **AK45-10 MIT 펌웨어 (`CMESC_MIT_APP_AK45_10.bin`, "MIT TEST V2", 5.1) 는 CAN 명령은 받는데 응답 프레임을 전혀 안 보냈다** [측정, 로봇]: 진입(FC), 0 명령, UART `run` 뒤 0 명령 20 개, `set_master_id` 0 → 16 모두 응답 0. 응답이 없으면 바퀴 속도를 모르니 균형이 불가능하다 → **바퀴는 서보 펌웨어로 되돌렸다**. 고관절은 MIT_v3 로 갈 예정.
로봇 코드(`motors.yaml`)는 모터마다 `protocol: servo | mit_v3 | mit_legacy` 를 고를 수 있다 (vcan 통합 시험 26/26).

### 7.3 UART (데스크톱에서 직접, 2026-10-02) [측정]

- 컨버터 QinHeng CH9102 (`1a86:55d3`, `cdc_acm`, `/dev/ttyACM0`), **921600 bps** 에서만 응답.
- 프레임: `0x02 | 길이 | 명령 + 데이터 | CRC16-XMODEM (상위, 하위) | 0x03`.
- **MIT 펌웨어의 UART 는 펌웨어 버전·부트로더·디버그 문자열 명령만** 받는다 (매뉴얼 V1.0.18 §5.3.1): `encoder` (각도 연속 출력, 약 20 Hz), `calibrate` (모터가 스스로 돌며 엔코더 보정 — **보정값을 새로 쓰므로 시험용으로 쓰지 말 것**), `exit`. 서보 직렬 명령(`GET_VALUES`, `SET_RPM` 등)은 서보 모드에서만 응답한다.
- 확인한 것: 펌웨어 "MIT TEST V2" 5.1, `encoder` → M ANGLE 5.075 rad, RAW 13230.

### 7.4 토크 상한 — 첫 기동 클램프

시뮬 바퀴 하나 토크 (마찰 + 보상 포함, 0.4 m/s 로 2 단 턱 점프 한 번) [측정]:
