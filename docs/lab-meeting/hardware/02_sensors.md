## 1. IMU — iAHRS RB-SDA-v1

### 1.1 사양 (매뉴얼 1.2, 1.4)

| 항목 | 값 |
|---|---|
| 내부 센서 | ICM-20948 (자이로·가속도·지자기) |
| 범위 | 자이로 ±2000 dps, 가속도 ±16 g, 지자기 ±4900 µT (설정으로 좁힘) |
| 자이로 잡음 밀도 | 0.015 dps/√Hz, 영점 초기 오차 ±5 dps |
| 가속도 잡음 밀도 | 230 µg/√Hz |
| 자세 필터 | 칼만 필터: 자이로 적분 + 중력으로 roll/pitch 보정 (+ 지자기로 yaw) |
| 정지 자세 정밀도 | roll/pitch 0.012 deg/h (제조사 평균) |
| 출력 | 오일러 (Z-Y-X), 쿼터니언, 원시값 |
| 전원·크기 | 4.2 – 12 V, 50 mA, 35 × 35 × 10 mm |
| 통신 | USB 가상 COM, 9600 – **921600** bps, 출하 115200 |

### 1.2 제어용 설정 [권장, 로봇 측 적용 예정]
`b2=921600`, `sp=2~5 ms` (200–500 Hz), `sd=0x008D` (1 ms 카운트 + 가속도 + 각속도 + 쿼터니언), `gs=1` (500 dps), `as=2` (8 g), `gl=3` (자이로 LPF 51.2 Hz), `mv=0` (지자기 보정 끔). 바꾼 뒤 `fw` → `rd`.

### 1.3 장착과 가감속 편향 — 제어 설계에 직접 걸리는 것

IMU 는 바퀴축(피치 회전중심)에서 약 20–30 cm 위에 있다. AHRS 는 가속도계로 중력 방향을 잡는다. 그래서 로봇이 전진 가속 $a_x$ 를 내면 겉보기 중력이 기운다.

```math
\Delta\theta_{\text{pitch}}\approx\arctan\frac{a_x}{g}\qquad(a_x=1\ \text{m/s}^2\ \Rightarrow\ 5.8^\circ)
```

두 바퀴 균형에서 이 크기는 치명적이다. 그래서 역할을 나눈다.
- $\dot\theta$ (피치 각속도): **자이로 y 를 직접** 쓴다(편향 없음). 추정각을 미분하지 않는다.
- $\theta$: AHRS 쿼터니언을 쓰되, 가감속 중 편향이 보이면 자체 상보필터로 바꾼다. 가속도 보정은 느리게 하고, 필요하면 바퀴 오도메트리 가속도로 보상한다.
- 정지 5 s 평균을 **정적 트림**으로 뺀다(`trim.txt`). 조립 기울기와 무게중심 편심 때문이다.

RL 정책 관측의 $g_b$(투영 중력)도 같은 편향을 받는다. 그래서 학습 때 관측 잡음 ±0.05 와 COM·질량 랜덤화를 넣었다.

## 2. GNSS + 지자기 (ESP32 허브 경유)

- 실제 모듈은 **NEO-M8N** 이다(UBX-MON-VER: `MOD=NEO-M8N-0`, SPG 3.01). 처음에 M9N 으로 알고 있었다.
- 230400 baud 로 저장돼 있었다 → 펌웨어를 230400 + 자동보율로 수정했다. 실내라 fix 는 없지만 NAV-PVT 5 Hz 수신을 확인했다.
- 초기 진단 교훈: 데스크톱 측정에서 GPS 바이트가 0 이어서 처음에 "보율 문제 아님"이라고 판단했는데, 실제 원인은 보율(230400)이었다. `gps_rx_bytes_lo16` 카운터를 프레임에 추가해서 원인을 구분할 수 있게 했다.

## 3. 전력 — PM02 V3 ×2

전압은 쓸 만하다. 전류는 **저전류에서 못 잰다**.

```math
V_{\text{shunt}}=I\,R_{\text{shunt}}=0.36\ \text{A}\times0.25\ \text{m}\Omega=90\ \mu\text{V}\ \ll\ \text{증폭기 오프셋}
```

- 컴퓨트 레일 전류는 Jetson INA3221 `VDD_IN` ÷ 팩 전압으로 대신 추정한다.
- 모터 레일은 수 A 이상이면 쓸 만하다.
- 배터리 잔량: 연결 2 s 뒤 휴지 전압으로 초기 SoC → 쿨롱 카운팅, 잔여시간 = (SoC − 20 % 예비) 에너지 ÷ 30 s 평균 전력.

## 4. 라이다·카메라

- **RPLIDAR C1**: 뒤쪽 위(고관절 중점 기준 −77 mm, 높이 122.5 mm)에 **뒤집어** 단다 → `laser` 프레임 yaw π. 확인 방법: 앞에 물체를 두고 rviz Fixed Frame = `laser` 로 본다.
- **IMX219**: 앞쪽(+108 mm). 광축 = `camera_link` +x.
- 둘 다 ROS 드라이버는 아직 없다(배송·케이블 문제).
