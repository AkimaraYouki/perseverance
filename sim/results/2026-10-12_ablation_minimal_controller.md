# 최소 제어기 + 요소별 추가 (2026-10-12, 실기 플랜트·실기 게인)

조건: climb_test.py TUNE 기본 (MIT 바퀴, 지연 10+5 ms, 백래시 0.3°, mit_pos 고관절 × 0.6, 실기 LQR 표, 롤 0.5/3/0, yaw 0.15/1.0).
최소 = LQR K(l) + VMC 높이 + 롤 PI + 회전 PI + 단순 가속 램프 (0.8 m/s²), 위치 유지 켬.
`--jerk_max 0 --lean_ff 0 --x_leak_moving 0 --x_hold_moving True --bal_adapt 0 --wheel_lpf_hz 0 --turn_slow False --turn_limit False --speed_guard 1.0 --brake_kp 0 --brake_ki 0`
robust: 11 종 × 8 대 (칸당 ±1–2 는 잡음), 험지: harsh --suite rough 1024 대 × 20 s.

- 험지 생존율은 어떤 요소로도 안 바뀜 (±1 %p) → 험지는 핵심 제어기 (특히 롤 이득) 가 정한다.
- 시뮬에서 효과가 확인된 추가 요소: 기울기 FF (멈추기), 회전 상한 (급회전), 속도 보호·브레이크 (급회전·경사).
- 시뮬에서 효과 없음: 새는 적분, 균형점 적응, 바퀴 LPF, S-curve 단독 — 이들은 실기 문제 (속도 넘침, IMU 장착 치우침, 15 Hz 떨림) 때문에
  붙었고 그 문제들이 시뮬에 정량 재현되지 않으므로, 실기에서 빼 보고 결정할 것.
- 전부 켠 것 (56) 이 효과 있는 셋을 합친 기대보다 낮음 — 칸당 8 대라 잡음 범위, 16 대로 다시 볼 것.
