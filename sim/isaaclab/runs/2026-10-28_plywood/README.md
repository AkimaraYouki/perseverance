# 합판 턱 점프 세트 (2026-10-28~29, 제2작전사령관배 드론봇 전투경연대회 1·2 일차 밤)

대회 턱이 미끄러운 합판이라 2 단째에서 앞으로 고꾸라짐 -> 턱 마찰을 낮춘 시뮬 (`jump_rl.py --box_mu`, multiply: 바퀴 0.5–0.8 × box_mu) 에서 CMA-ES.
결과는 로봇 `src/gen2_control/config/balance_tune_plywood.yaml` (`gen2_tune.sh plywood`, GCS GUI '점프 세트').

|---|---|---|---|---|
| 기본 | `ply.sh` | — | — | 0.5 / 35.2 / 73.5 % |

- 2048 판, 실기 보정 플랜트 (`--hip dc --hip_w0 29.3 --hip_cap_nm 15`, 고관절 실효 0.45–0.65), 칸 1 m, 턱 감지 모드.
- 스크립트의 `$D` 는 당시 작업 폴더 — 인자 파일 (`*_args.txt`) 은 여기 같이 있음.
- 교훈: 좋은 출발점에서 이어 갈 땐 `--cma_sigma 0.05`. 남은 실패는 착지 뒤 앞으로 미끄러짐 (마찰 한계).
