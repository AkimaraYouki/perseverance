# 잔차 RL (LQR+VMC 위 보정 정책) — 2026-09-26

기본 제어기 = LQR(바퀴) + VMC(다리, roll PI) + 상태 추정 + 속도 제한/브레이크 + 들림 감지 (`scripts/wbctrl.py`,
학습용 torch 벡터판 `tasks/residual.py`). 정책은 바퀴 토크 ±1.5 N·m, 다리 높이 ±2 cm 보정만 더한다.
학습: `pv train rl1` (Isaac-WheeledBiped-CAD-Residual-v0), 대회 지형 + 실기 조건 무작위 (질량 ±15 %, 무게중심 ±2 cm,
바퀴 모터 -15 %, IMU 바이어스·잡음, 지연 5 ms + 매 스텝 40 % 한 주기 더, 마찰 0.5~1.0, 밀기).

- 점프(상태머신) 포함 대회형 전체: 83/84 (98.8 %).
- rl1 -> rl2: 속도 추종 보상 1.0 -> 3.0 (1.0 이면 험지에서 천천히 가는 걸 배움), 엔트로피 0.002 -> 0.005.
  대신 대회보다 가혹한 조건 (9 cm 턱을 무작위 방향으로 내려가기, 좁은 차선 삼각형길) 은 rl1 보다 약함 -> 2.0 근처 시도 여지.

## 이 과정에서 찾은 기본 제어기 문제 (시험 세트 65 % -> 99 %)

1. 명목 질량 텐서를 복사 안 해 모델 오차가 제어기 모델까지 바꿈 (버그)
2. roll D 항 + 지연 -> 다리 발진 (roll 각속도 8 Hz 필터)
3. 뜬 바퀴가 헛돌아 속도 추정이 '후진' 으로 -> 땅 짚은 바퀴만, 부호 있는 고관절 토크로 접지 판정
4. 약한 모터 -> 전압(추정)으로 최고 속도 낮춤, 멈췄을 때만 균형점 보정
5. **roll PI 3/30/0.6 이 센서 잡음 + 지연에서 너무 셈 -> 1.5/15/0.3** (회전 중 바퀴 뜸의 원인)
6. 회전 중 안쪽 기울이기 (Ascento lean, 명령값으로), 회전 P 1.0 -> 0.5
7. 10 ms 고정 지연은 못 버팀 (5 ms 는 됨) -> 실기 제어 루프는 C++/Rust 실시간으로
