# 데스크톱 → 로봇: 바퀴 마찰을 시뮬에 넣은 결과 — 보상 필요 (0.25 N·m, 속도 tanh), 첫 기동 클램프 0.5 N·m 는 너무 작다

## 0. 먼저: 제어기가 하나로 합쳐졌다 (사용자 지시)
`wbctrl.py` 가 로봇 N 대를 배열로 계산한다. 실기·창은 N = 1, pv robust 수십, pv harsh 수천 — 모두 이 코드 (commit 894cff2).
pv harsh 가 쓰던 GPU 복제 제어기(residual.py)는 평가에서 뺐다. 실기 규격은 그대로 `wbctrl.py` (로봇 1 대 = 배열 길이 1).

## 1. 시뮬 바퀴 모델 (요청 1)
- PhysX 관절 마찰 (Isaac Sim 5.1, N·m 단위 확인: 정지 0.45 에 0.3 N·m -> 안 돎, 0.6 N·m -> (0.6 - 0.3)/관성 가속, `scripts/diag_wheel_friction.py`)
  - **정지 0.45 N·m, 운동 0.25 N·m** (운동은 추정: 너희 반전 가속 3 점을 a = (T + f)/I 로 맞추면 f ≈ 0.22, I ≈ 2.65e-3), 로봇·바퀴마다 ±30 %
  - 관성: 링크 1.84e-3 + armature 4.5e-4 = **2.29e-3 kg·m²** (제어기 LQR 모델에도 같은 값)
- 결과 (로봇마다 질량·무게중심·모터·센서 잡음·지연 다름):

| | pv robust 11 종 x 8 대 | pv harsh 4096 x 20 s (9 지형) |
|---|---|---|
| 마찰 없음 (기존) | 88/88 | 99.1 % [98.8, 99.4] |
| 마찰, 보상 없음 | **74/88** — 점프 0/8 (8 대 넘어짐), 손 들기 20° 2 대·경사로 2 대 넘어짐, 평지 정지 못 멈춤 2 | - |
| 마찰 + 보상 0.25 | **87/88** (점프 16 대: 마찰 없음 12/16 vs 13/16) | **98.7 %** [98.3, 99.0] (좁은 삼각형길 95.9 → 94.5 %, 나머지 같음) |

점프가 제일 크게 무너진 이유: 공중에서 바퀴를 반작용 휠로 쓰는 pitch PD 토크(작은 값)를 마찰이 먹는다.

## 2. 마찰 보상 (요청 2) — 필요하다. 이 형태로:
```
바퀴마다 (L, R 따로):  τ_cmd += 0.25 · tanh(ω_joint / 0.5 rad/s)      [N·m]
  ω_joint = 그 바퀴 엔코더 관절 속도 (+y 규약, 바퀴-다리 상대 속도 = 마찰이 걸리는 속도)
  더하는 곳: LQR + 회전(yaw) 분배 뒤, 토크 → 전류 변환 전. 들림 감지 중(바퀴 감쇠 모드)에는 더하지 않는다
```
- 크기 = **운동 마찰** 값. 0.4 (과보상) 는 점프 5/8 로 나빠졌다. 1 kHz 감속 실측이 나오면 그 값으로 바꾼다 (TUNE `fric_comp_nm`).
- 멈춘 순간(ω≈0)엔 보상이 0 이라 정지 마찰은 LQR 이 넘는다. 옵션 `fric_comp_static_nm` (거의 멈췄을 때 지령 방향으로 더함) 은 삼각형길에서 +0.2 %p 뿐이라 기본 끔.
- `wbctrl.py` 의 `# 바퀴 마찰 보상` 블록이 규격.

## 3. 토크 상한 (요청 3) — 0.5 N·m 클램프는 쓰지 말 것
시뮬 바퀴 하나 토크 (마찰 + 보상 포함, 0.4 m/s 로 2 단 턱 점프 한 번):
| 구간 | 중앙 | 99 % | 최대 |
|---|---|---|---|
| 주행·정지 | 0.29 | 0.49 | 0.58 N·m |
| 점프 (공중 PD·착지) | 0.30 | 4.96 | 5.16 N·m |
- 평지에서도 0.5 에 걸린다 (정지 마찰만 0.45). **첫 균형 시험은 1.5 N·m 이상**, 점프·험지는 피크 6.35 N·m (5 A) 까지 열어 둘 것.
  (험지·급회전 분포는 아직 안 쟀다 — 더 크다.)

## 4. 확인 부탁
1. **0.4 A 이하가 안 도는 원인이 마찰인지 드라이브 데드밴드인지**: 보상 형태가 다르다.
   마찰이면 위 속도 tanh 보상, 데드밴드(드라이브가 작은 지령을 0 으로)면 **지령 방향으로 항상 0.4 A 를 더해야** 한다.
   구분법: 0.3 A 를 주고 손으로 바퀴를 천천히 돌려 본다 — 마찰이면 모터가 돕는 방향 토크가 느껴지고, 데드밴드면 아무 힘도 없다.
   (시뮬엔 `wheel_deadband_nm` 옵션이 있어 바로 비교 가능.)
2. 1 kHz 감속 실측 (운동 마찰 값) — 보상 크기를 정한다.

## 참고: 시뮬에서 본 다른 문제
마찰이 있으면 **제자리에 멈춰 서 있을 때 몸이 앞으로 5~6° 기운 채 수 mm/s 로 밀려간다** (2 단 턱 위에서 멈춘 뒤 60 s 동안 2 m).
위치 오차 적분(x_err, ±0.3 m 제한)으로 되돌리는 토크가 정지 마찰보다 작아서로 보임 — 확인 중. 실기 첫 정지 시험에서 볼 것.
