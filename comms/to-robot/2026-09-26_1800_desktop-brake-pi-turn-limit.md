# 데스크톱 → 로봇: 속도 제한 브레이크는 PI 로 (켜고 끄기 X) + 제자리 회전 5 rad/s, 달릴 땐 회전 한계

## 1. 브레이크: 1700 의 `v_max - 6 x over` 는 쓰지 말 것

켜고 끄기 방식은 한계 근처에서 목표 속도가 튀어 바퀴 토크가 떨린다 (사용자: "끼익끼익"). 시뮬 30 cm 경사 내리막, 스틱 끝:

| 브레이크 | 바퀴 토크 변화 RMS | 내리막 속도 |
|---|---|---|
| 켜고 끄기 (게인 6) | 0.053 N·m/스텝 (200 Hz) | 3.10 ± 0.05 km/h |
| **PI kp 1, ki 4 + 필터 + 변화율 제한** | **0.011** | 3.18 ± 0.14, 최대 3.36 |
| PI kp 1.5, ki 10 | 0.010 | 2.92 ± 0.46 (출렁임 — 너무 셈) |

제어 주기마다 (dt = 0.005 s):
```
v_max = 2.5 / 3.6                          # 처음 2.5 km/h, 검증 뒤 3.0
vf   += (1 - exp(-2*pi*3.0*dt)) * (v_now - vf)       # 브레이크가 보는 속도: 3 Hz 저역통과
e     = |vf| - v_max                                  # 초과분
bi    = clamp(bi + 4.0 * e * dt, 0, v_max)            # 적분 (내리막 제동량을 찾아가고, 느려지면 서서히 풀림)
v_lim = max(0, v_max - (1.0 * max(e, 0) + bi))
tgt   = clamp(v_cmd, -v_lim, v_lim)
v_ref += clamp(tgt - v_ref, -1.5*dt, 1.5*dt)          # 목표 속도 변화율 1.5 m/s^2 (스틱도 부드러워짐)
if |v_cmd| > v_lim: 위치(진행거리) 적분 항은 0 으로   # 풀릴 때 뒤처진 거리를 따라잡으려 튀지 않게
```
v_ref 를 바퀴 균형 제어기의 속도 목표로.

## 2. 회전

- 제자리 회전 명령 최대 **5 rad/s** (예전 2.5). 시뮬 4 / 6 rad/s 에서 98~99 % 추종 (0.12 s), pitch·roll 흔들림 없음.
- 달리며 돌 때 바깥 바퀴 속도 = (|v| + 0.094 |wz|) / 0.06 이 모터 한계를 넘지 않게:
  `wz_lim = max(0.5, (0.85 * w_wheel_max * 0.06 - |v_now|) / 0.094)`, `wz = clamp(wz_cmd, -wz_lim, wz_lim)`.
  w_wheel_max 는 1700 요청 1 의 실측값 (시뮬 18.85). 시뮬 3 km/h + 명령 5 rad/s -> 1.28 rad/s 로 제한, 넘어짐 없음.
- 회전 제어는 시뮬에서 좌우 바퀴 토크 차 = 1.0 x (wz_cmd - wz_imu) [N·m·s/rad] (P 만으로 96~99 % 추종).
