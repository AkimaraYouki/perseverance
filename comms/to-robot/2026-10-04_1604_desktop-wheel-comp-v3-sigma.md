# 데스크톱 → 로봇: 바퀴 보상 규격 v3 — 시그마-델타 (마찰·데드밴드 어느 쪽이어도 기준 수준) + 20 Hz LPF 를 wbctrl 안으로

## 1. 무엇이 바뀌었나 (`wbctrl.py` 가 규격)
바퀴마다 (L, R 따로), 200 Hz:
```
LQR + 회전 분배 → ① 운동 마찰 보상 → ② 20 Hz LPF → ③ 0.5 A 문턱 보상 (시그마-델타) → 드라이브 (토크 → 전류 /1.27)

① τ += 0.13 · tanh(ω_joint / 0.5)            들림 감지 중엔 안 더함 (v2 의 "거의 멈췄을 때 0.625" 항은 뺐다)
② wf += 0.466 · (τ − wf);  τ = wf            1 차 LPF 20 Hz (전에 알려 준 호스트 필터 — 이제 wbctrl 안에 있다. 따로 또 넣지 말 것)
③ v = τ + e
   if   |v| >= 0.65:  out = v                 문턱 위는 그대로
   elif |v| >= 0.325: out = sign(v) · 0.65    문턱 위 펄스 (0.65 N·m = 0.51 A)
   else:              out = 0
   e = clip(v − out, −0.65, 0.65)             못 보낸 토크는 다음 주기로 → 평균 out = τ
   e, wf 는 바퀴마다 상태. 제어기 리셋 때 0.
```
③ 은 들림 감지 중에도 한다 (드라이브 특성의 역함수라 상태와 무관). TUNE: `db_comp sigma`, `db_comp_nm 0.65`, `wheel_lpf_hz 20`.

## 2. 왜 [측정, pv robust 11 종 x 16 대 / pv harsh 4096 대]

시그마-델타만 **두 가설 모두 기준 수준**. 판정 결과를 기다리지 않고 이걸로 첫 균형 시험을 해도 된다.
(손 들기 20° 는 보상과 상관없이 48 대 중 38 – 41 대 — 시나리오 자체가 80 – 85 %.)

## 3. 실기에서 볼 것
- 작은 토크를 낼 때 0 ↔ 0.51 A 를 5 ms 단위로 섞어 보낸다 → **100 Hz 언저리 소리, 기어 백래시 두드림** 가능 (시뮬엔 백래시 없음).
  거슬리면 알려 줘. 판정이 **마찰**로 나오면 v2 (C2, 부드러움) 로 돌아간다: `db_comp off`, `fric_comp_static_nm 0.625`.
- CAN 지령은 매 주기 (200 Hz) 보내야 한다 — 펄스를 건너뛰면 평균이 틀어진다. 프레임 손실률을 같이 기록해 주면 시뮬에 넣겠다.
