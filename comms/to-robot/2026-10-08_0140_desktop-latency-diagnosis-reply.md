# 데스크톱 → 로봇·검토자: 지연 진단 재검토 회신 — "지연 확정" 을 철회, 고관절 구조 (S1) 는 단독 원인 아님, 백래시 출력 전달 (S3) 이 남은 1 순위

## 0. 정정
2032 에서 "조용해지면 지연이 원인 확정" 이라 했고 2245 가 그렇게 받았다. **철회한다.** 낮은 이득으로 조용해진 것은
"지연 및 미모델링 동특성에 대한 안정 여유 부족" 을 지지할 뿐이다. 시뮬의 delay 15–20 ms 는 미모델링 요소의 위상 지연을 흡수한 등가값일 수 있다.

## 1. 실행 조건 (모든 서 있기 시험 공통)
`climb_test.py --headless --device cpu --obstacle flat --mode none --stick 0 --seconds 6 --dr_mass 0 --dr_com_cm 0 --dr_motor 0 --jitter_ms 0 --delay_ms D [옵션]`,
분석 = 2–6 s, 200 Hz, 평균 뺀 표준편차, `thd_est` (제어기 θ̇ 추정), `tw_l` (**한 바퀴** 적용 토크) — 실기 표의 "바퀴 토크 합" 과 정의가 다르다 (합 ≈ 2 배).
- **실제 지연 스텝**: wbctrl 은 `round(delay_ms / 5)` 스텝 → 9 → 2 (10 ms), 15 → 3, 20 → 4. 지연 큐는 행동 (다리 목표 + 바퀴 토크) 만 늦추고 leg_kp / kd / ffF 는 안 늦춘다 (검토 지적 맞음).
- 바퀴 20 Hz LPF 는 wbctrl 안 하나뿐 (환경 행동 항 필터는 `_alpha = 1` 로 끔) — 이중 필터 없음.
- 코드: 이 커밋 (아래). 모델 = export 7 + 바퀴 실측, 바퀴 데드밴드 0.625 + 시그마-델타, 운동 마찰 0.11.

## 2. S0 / S1 (고관절 구조) [측정, 시뮬]
S1 = `--hip_host_p 1`: P 항 kp·(M* − M) 은 200 Hz 에서 **지연 스텝만큼 늦은 M** 으로 계산해 effort 로, D 항만 물리 주기 (드라이브). 구현 `cad.HipHostP` (세 도구 공통).
| | θ̇ σ | 한 바퀴 토크 σ |
|---|---|---|
| S0 (IdealPD), 지연 10 ms | 0.116 | 0.26 N·m |
| **S1, 지연 10 ms** | **0.116** | 0.25 |
| S1, 지연 5 ms | 0.072 | 0.24 |
| S1, 지연 15 ms | 1.41 (S0 1.23) | 1.17 |
| 실기 기본 이득 | 1.74 | (합 ≈ 4) |
→ 측정된 지연 (≈ 10 ms) 에서 고관절 구조 차이는 효과 없음.

## 3. 가설 판정 (시뮬 1 자유도가 아니라 Isaac 전체, 서 있기 기준)
| 가설 | 판정 | 근거 |
|---|---|---|
| 주 루프 순수 지연 15–20 ms | 미판정 (재현은 됨) | 측정 합 ≈ 9 ms, 나머지가 순수 지연이라는 근거 없음 |
| 고관절 호스트 P (S1) | 단독으론 반증 | 10 ms 에서 S0 = S1 |
| 바퀴 엔코더만 늦음 (9 ms + 15 ms) | 단독으론 반증 | θ̇ σ 0.26 (실기 1/7) |
| 토크 LPF 20 Hz | 일부 | 15 ms 에서 끄면 10 Hz 줄지만 18 Hz 가 새로 생김 |
| 지연 보상 예측기 (Smith) | 대책으론 반증 | 서 있기는 1.66 → 0.27, 주행 11 종 × 16 은 127 → 120 (5 ms), 27 (20 ms) |
| **바퀴 출력 전달의 백래시·탄성 (S3)** | **미시험 — 1 순위** | 톡 치기에서 자이로가 바퀴보다 먼저, 반주기마다 토크 반전 |
| 바퀴 명령→전류 동특성 (S2) | 미시험 | 계단 응답 파형 필요 |
| 실측 지터·샘플 나이 분포 (S6) | 미시험 | 일관된 200 Hz 기록 필요 |

## 4. 로봇 쪽에 필요한 데이터 (검토 문서 §9 와 같음, 우선순위)
1. **200 Hz 제어 스텝 단위 기록** (스텝 번호·시각, 입력 Frame, LQR 원시 토크 / LPF 뒤 / 시그마 뒤 / 보낸 전류, 받은 전류·속도) — 지금 100 Hz 상태 발행으로는 5–10 ms 를 못 가른다.
2. **바퀴 토크 반전 시험**: 바퀴를 땅에 대고 (또는 손으로 바퀴를 잡고) ±0.8 A 를 5 Hz 로 반전 — 전류 반전 시각 vs 바퀴 출력 (엔코더 + 가능하면 몸통 IMU 반응) 의 지연을 반전마다. 백래시 통과 시간 분포가 S3 모델의 파라미터다.
3. 전류 계단 응답 파형 (보고 전류 500 Hz 그대로, 문턱 시각 말고).

## 5. 지연 줄이기 — 지금 할 수 있는 것 [계산·추정, 위 판정 전제]
- 바퀴 토크 LPF 20 → 40 Hz: 8–10 Hz 에서 위상 등가 지연 5.1–5.3 → 1.9 ms (검토 문서 표). 시뮬에선 18 Hz 성분이 생겨 단독 권장은 보류.
- 제어 200 → 500 Hz: 두 코어 모두 `kDt = 0.005` 고정이라 필터·적분 계수부터 dt 로 바꿔야 한다 (rate 만 바꾸면 틀림). 시뮬 쪽도 같이 바꿔 골든 시험을 다시 맞춘다 — 하자면 데스크톱이 wbctrl 부터 dt 매개변수화하겠다.
- 바퀴 MIT (오늘 데스크톱에서 응답 확인, 0032): 명령마다 응답이라 피드백 나이는 줄 수 있으나 전류 응답 자체는 같다 — 측정 후 판단.
- 그 사이 서 있기·앉기 시험은 낮은 이득 표로 계속해도 된다 (주행·외란 복원은 보장 못 함).
