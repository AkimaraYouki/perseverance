# 데스크톱 → 로봇: IMU 지연이 균형의 급소 — iAHRS 설정 정정 (`gl=0`, `sp=2`) + 지연 실측 요청

## 1. 왜: 시뮬에서 IMU 지연 몇 ms 차이로 성공률이 무너진다

GPU 가혹 평가 (`pv harsh`, 로봇 4096 대 x 20 s, 험지 12 종, 3 km/h, 실기 조건 전부) 에서
IMU 고정 지연만 바꿨다. 평균 나이 = 고정 지연 + 출력 주기 절반 + 흔들림.

| IMU 고정 지연 | 평균 나이 | 성공률 |
|---|---|---|
| 4 ms | 약 7.5 ms | 95.8 % |
| 8 ms | 약 11.5 ms | **81.4 %** |
| 12 ms | 약 15.5 ms | **47.6 %** |
| 20 ms | 약 23.5 ms | **5.6 %** |

- 넘어지는 시간 상수가 약 0.09 s (LQR 모델 열린 루프 극점 10.7 rad/s) 라 10 ms 대 지연이 치명적이다.
- 자세각만 자이로로 앞당기는 보상(θ + θ̇ x 지연)은 효과 없음 (8 ms: 81.4 -> 79.8 %, 12 ms: 47.6 -> 45.8 %).
  문제는 **자이로 각속도(θ̇) 자체가 늦는 것**이다. 그러니 하드웨어 쪽에서 줄여야 한다.

## 2. 지연 예산 (매뉴얼 `docs/vendor/IAHRS_manual_...pdf` 기준)

| 단계 | 근거 | 0130 권장 | **새 권장** |
|---|---|---|---|
| 자이로 내장 LPF `gl` | 4.2.28: 3 = 51.2 Hz, 0 = 196.6 Hz | 약 3.1 ms | **`gl=0` 약 0.8 ms** |
| 내부 처리 | 4.3.1: 센서 읽기·칼만 1 kHz | 약 0.75 ms | 같음 |
| 출력 주기 `sp` | 4.2.20: 1~60000 ms, 샘플 사이는 묵은 값 | 5 ms -> 평균 2.5 ms | **`sp=2` 평균 1 ms** |
| 직렬 (ASCII 921600) | 카운트+가속도+각속도+쿼터니언 약 90 B | 약 1 ms | 같음 |
| USB + 읽기 | 가상 COM, 칩 미상 | 약 1 ms | FTDI 면 `latency_timer`=1 |
| **평균 합계** | | **약 8.4 ms** | **약 4.5~5 ms** |

- 새 권장 조건(+ 제어 스레드 실시간)에 해당하는 시뮬 결과: 험지 합계 **98.9 %** (지금 권장 조건 약 95 %).
- `gl=0` 잡음: 매뉴얼 잡음 밀도 0.015 dps/√Hz x √230 Hz ≈ 0.23 dps (0.004 rad/s). 시뮬 가정(0.01 rad/s)보다 작다.
  **모터 진동이 자이로에 실리면** `gl=1` (151.8 Hz) 이나 `gl=2` (119.5 Hz) 로 한 단계씩. 51.2 Hz 까지는 내리지 말 것.
- 가속도 LPF `al` 은 자세 보정(칼만)과 들림 판정용이라 지금 값 유지해도 된다.

## 3. 설정 (정정본)

`b2=921600`, **`sp=2`**, `sd=0x008D` (1ms 카운트 + 가속도 + 각속도 + 쿼터니언), `gs=1` (500 dps), `as=2` (8 g),
**`gl=0`**, `mv=0`. 바꾼 뒤 `fw` -> `rd`.

## 4. 실측 요청 (시뮬 가정을 실기 값으로 바꾸려고)

1. **USB 칩**: `lsusb` VID:PID 와 커널 드라이버 (`cdc_acm` / `ftdi_sio` / `cp210x` / `ch341`).
   `ftdi_sio` 면 `/sys/bus/usb-serial/devices/ttyUSB*/latency_timer` 를 1 로 (기본 16 ms — 200 Hz 흘려보내면 실제 추가 지연은 약 한 주기지만 끊기면 16 ms).
2. **수신 간격**: 1 ms 카운트와 젯슨 수신 시각(steady_clock)을 10 s 기록 -> 간격 평균·표준편차·최대, 누락 수.
   (절대 지연은 카운트만으론 안 나온다. 가능하면: 로봇을 손으로 톡 쳐서 자이로 스파이크 시각과 바퀴 엔코더(CAN) 반응 시각 비교.)
3. **CAN 피드백 500 Hz** (사용자가 바꿨다고 함): 모터별 0x29 수신 간격 실측.
4. **제어 루프가 생기면**: 200 Hz 주기 간격 히스토그램과 최대 간격. 시뮬에서 명령이 20 ms 끊기는 일이 초당 0.4 번이면 -4 %p 였다.
   `SCHED_FIFO` + 코어 고정 권장.

## 5. 참고 (정보)

- **바퀴 크기** (사용자 제안, 시뮬 실기 추정 조건 0.8 m/s): 지름 120 mm 95.8 % / 130 96.8 / 140 97.4 / 150 97.8 %
  (넘어짐 172 -> 91 대). 넘어짐은 거의 바퀴가 모터 속도 한계 근처일 때 난다 -> 큰 바퀴가 같은 속도에서 토크 여유를 늘린다.
- 1700 의 AK45-10 무부하 속도 vs 전압 측정도 아직 필요하다 (바퀴 크기 판단에 직접 들어감).
