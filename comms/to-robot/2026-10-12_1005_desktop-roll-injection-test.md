## 왜
롤 이득을 측정으로 고르려면 "다리 좌우 차 명령 → 몸 롤" 응답 (다리 + 몸통) 이 필요하다.
- 10-09 (hip mit, 롤 1.0/8/0, 진동 중) [측정]: Δh_tgt→Δh 2.73 Hz 0.47∠−149° — 명령이 커서 믿을 만했다.
- 10-10 mit_pos 기록 3 개 (롤 0.5/3/0) [측정]: 같은 분석이 2–4 Hz 에서 ~180° 로 나온다. 하지만 Δh_tgt 표준편차 2 mm 로 명령이 작아,
  바닥·주행 외란이 다리를 직접 미는 폐루프 착시일 가능성이 크다 → **이 데이터로는 mit_pos 다리가 빨라졌는지 판단 불가.**
→ 아는 신호를 넣어 그 신호 기준으로 재면 (주입 신호 = 도구변수) 착시 없이 열린 루프 응답이 나온다.

## 1. 코드 (balance_node 또는 wb_core 롤 출력 뒤, 기본 꺼짐)
roll PI 출력 dlt (= hL_tgt − hR_tgt) 에 주입 신호를 더한다:
  dlt_cmd = dlt + inj(t),  inj(t) = A · sin(2π ∫f(t)dt),  f(t) = f0 · (f1/f0)^(t/T)   (로그 처프)
파라미터: roll_inj_amp_mm (기본 0 = 끔), roll_inj_f0 0.5, roll_inj_f1 8.0 [Hz], roll_inj_s 20 [s]. 시작은 서비스/파라미터 설정 시점, T 지나면 자동 0.
처음·끝 0.5 s 는 진폭을 sin² 로 올리고 내림. 다리 목표 한계 (H_MIN/H_MAX, level_max) 는 그대로 적용.
**step 기록에 열 추가: roll_inj (주입 Δh [m]), dlt (주입 전 롤 PI 출력 [m])** — 나머지 열 (roll, gx, h_tgtL/R, hL/R, hip_tau, hip_cur) 그대로.

## 2. 시험 (평지, 손 안 댐, 패드 0, 균형 중)
| # | 롤 이득 | 주입 진폭 | 비고 |
|---|---|---|---|
| a | 0.5 / 3 / 0 (지금) | ±3 mm | 기본 |
| b | 0 / 0 / 0 (롤 끔) | ±3 mm | 순수 다리+몸통 응답 (롤 PI 없이). 20 s 뿐이라 기울어져도 손으로 받칠 준비 |
| c | 0.5 / 3 / 0 | ±6 mm | 진폭 선형성 확인 (a 와 같은 응답이면 OK) |
각 20 s, 200 Hz step 기록 → comms attachments 로. 흔들림이 커지면 (roll > 5°) 바로 끊어도 됨.

## 3. 받으면 데스크톱이 할 것
roll_inj 기준으로 inj→Δh, inj→roll 응답 (0.5–8 Hz) → 롤 PI (kp, ki, kd, roll_rate_lpf 8 Hz) 를 곱해 열린 루프 이득·위상 여유 계산 →
**위상 여유 ≥ 45°, 이득 여유 ≥ 6 dB 인 가장 센 롤 이득**을 추천 (10-09 의 1.0/8/0 이 2.8 Hz 에서 여유 0 이었는지도 같이 확인).
같은 측정으로 시뮬 고관절 (hip_gain_eff 0.6) 을 맞춰서 시뮬 롤 결과도 다시 낸다.
