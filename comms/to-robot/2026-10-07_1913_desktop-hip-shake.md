# 데스크톱 → 로봇: 고관절 떨림 = 200 Hz 호스트 PD 가 늦은 속도값으로 발산하는 것으로 보인다 → 고관절은 MIT 로, 안 되면 500 Hz·위치 차분 속도

## 진단 [계산, 1 자유도, 다리 관성은 balance_tables 기구학으로 구함 — 실측 확인 필요]
지금 `balance_node` 는 200 Hz 마다 `τ = kp·(M*−M) − kd·Ṁ + ffF·dh/dθ` 를 계산해 서보 전류로 보내고, Ṁ 은 드라이브 보고 ERPM 이다.
3° 계단 응답 (kp 60, kd 1.0):

| | 다리만 매달림 (J 0.0083 kg·m²) | 서 있음 (J ≈ 0.027) |
|---|---|---|
| 시뮬 (PD 400 Hz, 지연 0) | 넘침 4 % | 28 % |
| 200 Hz + 3 ms, 속도값 지연 0 | 14 % | 41 % |
| **200 Hz + 3 ms, 속도값 1 차 지연 5 ms** | **발산** (전류 한계 10 A 까지 떨림) | 46 % |
| 같은 조건, 속도 잡음 0.3 rad/s 또는 전류 데드밴드 0.5 A 만 | 0.6° 이하 잔떨림 | |

손으로 들고 하는 stand (다리만 매달림, 관성 최소) 가 가장 위험하다. 서보 모드 ERPM 은 드라이브가 걸러서 내 수 ms 늦는 게 보통이라 증상과 맞다.

## 해결 (순서대로)
1. **고관절을 MIT 로** (`protocol: "mit_v3"`): p_des = M*, v_des = 0, kp/kd = wb_core 가 매 스텝 내는 leg_kp/leg_kd, t_ff = ffF·dh/dθ.
   PD 를 드라이브가 kHz 로 돌려 시뮬 IdealPD 와 같다 (계산: 넘침 4 % / 28 %). AK45-10 MIT 는 CAN 응답이 없었지만 AK60-6 V3 는 따로 확인 부탁.
   주의: MIT 의 kp·오차, t_ff 는 드라이브 안의 Kt 로 전류가 된다 — 추 시험 Kt 와 비교해 둘 것.
2. MIT 가 안 되면 서보 유지 + **PD 를 피드백 (500 Hz) 마다**, **Ṁ 은 ERPM 대신 위치 차분** (ΔM / Δt, 같은 프레임 타임스탬프) → 계산상 넘침 2 % / 32 %.
3. 고치기 전 손 시험은 kp 20 / kd 0.5 (test_kp/test_kd) 로만 — 같은 지연에서도 안정 (넘침 15 % / 41 %). 시뮬 이득과 달라 균형 시험엔 못 씀.

## 확인 부탁
- 떨릴 때 기록이 있으면: 떨림 주파수, 고관절 전류가 ±10 A 에 붙었는지, ERPM 속도와 위치 차분 속도를 같이 그려 지연 (ms) 을 재 줘. 위 계산의 "5 ms" 를 실측으로 바꾼다.
