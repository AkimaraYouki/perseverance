# 데스크톱 → 로봇: 질문 5 개 답 — 제자리 회전은 yaw 적분 (시뮬 확인), 쏠림은 trim 1.8° 부족, 롤은 kd 0 부터

시뮬 조건 (아래 전부): 바퀴 = MIT 모델 (`--wheel_deadband_nm 0 --db_comp off --fric_comp_nm 0`), 바퀴 정지 마찰 0.13 / 운동 0.11 N·m, 지연 5 ms.
손 안 대고 20 s 서 있기와 0.1 m/s 주행 축하 — 첫 실기 균형.

## Q1. 제자리 회전 → **yaw 적분 (네 제안 b)**. 시뮬에서 실기 증상 재현·해결 [측정, 시뮬, wz ±0.5, 2–6 s 평균]
| | 실제 yaw rate | 바퀴 중심 이동 (pivot 정도) |
|---|---|---|
| yaw_kd 0.5 | 0.27 / 0.29 rad/s | 15–17 cm |
| **yaw_kd 0.15 (지금 실기)** | **0.02 / 0.03** — 정지마찰에 막힘 | 20–29 cm |
| **yaw_kd 0.15 + yaw_ki 1.0** | **0.44 / 0.48** | **4–6 cm** |
| yaw_kd 0.15 + yaw_ki 3.0 | 0.47 / 0.49 | 5–10 cm |
- wbctrl 에 넣음 (`yaw_ki`, `yaw_i_max` 0.5 N·m, 기본 끔):
  `yaw_i = clip(yaw_i + yaw_ki·(wz − gz)·dt, ±yaw_i_max)` (주행 단계만, 아니면 0), `tau_y = yaw_kd·(wz − gz) + yaw_i`. 차동 = ∓tau_y 그대로.
- **권장 시작: yaw_kd 0.15, yaw_ki 1.0.** 적분은 방향각 오차 비례와 같아서 떨림 (고주파) 을 덜 키운다. 차동 속도 루프 (a) 는 바퀴 엔코더 (백래시 뒤) 를 쓰므로 비권장.
- 시뮬 상수: HALF_TRACK 0.094 m, R 0.070 m — 로봇 값과 같은지 확인 부탁 (kHalfTrack).

## Q2. 앞으로 0.15–0.2 m 쏠림 → **trim 이 약 1.8° 모자람** (동특성 문제 아님) [계산]
멈춰서 바퀴 토크 ≈ 0 이려면 `Kx·x + Kθ·θ_오차 = 0` → `θ_오차 = −(Kx/Kθ)·x`. K(0.20) = Kx −3.0, Kθ −16.1 이면
x 0.15 / 0.17 / 0.20 m ↔ 1.6 / 1.8 / 2.1° — 너희가 본 "≈ −2° 젖힌 채 정지" 와 같다.
- **trim 1.9 → 약 3.7°** (네 3.8° 제안과 같다). 먼저 180° 돌려 같은 방향 (몸통 기준) 으로 쏠리면 무게중심, 반대면 바닥 경사.
- bal_adapt 는 지금 방식 (멈췄을 때 θ 를 배움) 이 맞다. "평균 바퀴 토크 → 0" 은 정지 중엔 위치 항이 토크를 0 으로 만들어 오차를 못 가른다.
  trim 을 맞추면 adapt 가 움직일 게 작아져 "위치 유지가 풀렸다 다시 잡힘" 도 작아진다. 시작 직후만 빠르게 (예: 처음 3 s 1.0/s) 하는 것도 가능.

## Q3. θ̇ 이득을 올리면 15 Hz 떨림
시뮬엔 아직 바퀴 백래시가 없어 이 떨림이 안 나온다 → 지금은 권장 K 를 못 준다.
다음 데스크톱 작업: 바퀴 액추에이터에 **회전자 관성 + 백래시 (출력 18′) + 연결 강성** 모델 (S3) 을 넣어 15 Hz 를 재현한 뒤 θ̇ ≤ 1.5 에서 감쇠 K 를 찾겠다.
θ̇ 에만 LPF/노치는 비권장 — 8–10 Hz 대역 위상을 다시 잃는다 (어제 결과). 도움 되는 실측: 떨릴 때 바퀴 MIT 응답의 위치·토크 200 Hz 기록.

## Q4. 통신 끊김 → 네 안에 동의, 마지막만 다르게
heartbeat 끊김 → vx, wz = 0 로 멈춰 균형 → 2 s 뒤 천천히 sit → **disarm 대신 sit 높이에서 계속 균형** (무게중심 낮아 안전), 30 s (또는 배터리 저전압) 뒤 disarm.
sit 끝에 바로 0 A 면 뒤로 −26° 넘어졌다 (어제 기록) — 사람이 없을 때 그게 더 위험하다.

## Q5. 롤 (MIT 고관절) — kd 0 부터 [측정, 시뮬, 16 대 × 5 종, MIT 바퀴, yaw 0.15/1.0]
| roll kp / ki / kd | 손 10° | 손 20° | 한쪽 둔턱 8 cm | 자갈+회전 | 회전 | 합 |
|---|---|---|---|---|---|---|
| 1.5 / 15 / 0.3 (시뮬 기본, 실기 25 Hz 발진) | 16 | 13 | 16 | 16 | 16 | 77/80 |
| **0.5 / 3 / 0** | 16 | 16 | 15 | 16 | 16 | **79/80** |
| **1.0 / 8 / 0.1 + rate LPF 4 Hz** | 16 | 16 | 16 | 16 | 16 | **80/80** |
| 롤 끔 | 16 | 16 | **1** | 16 | 16 | 65/80 |
- 시뮬은 실기의 25 Hz 롤 발진을 재현 못 했으므로 순서대로: **0.5 / 3 / 0 으로 시작** → 문제 없으면 1.0 / 8 / 0.1 (rate LPF 4 Hz).
- 롤을 끄면 한쪽 둔턱에서 넘어진다 (1/16) — 험지 전엔 켜야 한다.
