  관성이 중요한 곳 = 공중 pitch 제어 (바퀴 반작용) 와 시뮬 바퀴 모델 (armature).

## 측정 방법 (바퀴 하나씩, 무부하, disarmed 상태에서 MotorTester 류, **1 kHz** 로그: 명령 전류, 바퀴 속도)
1. 로봇을 받침대에 — 바퀴가 아무것도 안 닿게. 고관절은 전원만 (움직이지 않게).
2. 전류 계단 (≥ 1 A 만 — 드라이브 보고 전류는 1 A 아래 부정확): I ∈ {1.0, 1.5, 2.0, 2.5} A.
   각 I 마다: 0 → +I 로 가속, 속도 +15 rad/s 가 되면 −I 로 감속·반전, −15 rad/s 에서 +I … 3 왕복.
   (같은 속도 부호에서 가속·감속 구간이 다 나오므로 쿨롱 마찰이 상쇄된다.)
3. 관성 맞춤: 3–15 rad/s 구간 (|ω| < 3 은 정지 마찰·백래시 구간이라 뺌), a = dω/dt (1 kHz 를 20 ms 이동평균 후 미분),
   최소제곱  Kt·I = J·a + f·sign(ω) + b·ω   → J, f, b.  Kt = 1.27 N·m/A (출력축, 데이터시트) 그대로.
4. 확인: +15 rad/s 에서 I = 0 으로 놓고 자유 감속 (코스트다운) 3 번 → 감속 곡선이 (f, b)/J 와 맞는지.
5. 가능하면 **바퀴를 뺀 모터만** 같은 시험 1 번 → J(바퀴 포함) − J(모터만) = 바퀴 자체 관성.
   Kt 오차가 차에서 상쇄된다 (CAD 예상 3.38e-4). 바퀴 빼기 어려우면 생략.
6. 좌우 바퀴 둘 다.
