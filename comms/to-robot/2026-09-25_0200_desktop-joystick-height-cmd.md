# 데스크톱 → 로봇: 명령 구조 변경 (vx, wz, 높이) + 조이스틱 매핑

사용자 요청으로 오리 로봇 프로젝트(github AkimaraYouki/SummerProject)의 조이스틱·명령·학습 구조를
이 로봇에 옮겼다. 실기 조종을 만들 때 **같은 매핑·같은 명령 정의**를 쓰면 시뮬과 실기가 맞는다.

## 명령 (정책 입력, 3개)

| 순서 | 의미 | 범위 | 단위 |
|---|---|---|---|
| 0 | 전진 속도 vx | -0.45 ~ 0.45 | m/s |
| 1 | 요 각속도 wz (반시계 +) | -1.0 ~ 1.0 | rad/s |
| 2 | 다리 높이 기준 h_ref = 고관절~바퀴중심 관절값 | 0.130 ~ 0.235 | m (h = +60 mm, 190~295 mm) |

- 이 로봇은 옆으로 못 가므로 "6방향" = 전진/후진, 좌/우 회전, 올라가기/내려가기.
- **높이는 속도 제한 0.10 m/s 로 목표를 따라간다** (`commands.py`). 실기도 목표 높이를 이 속도 이하로 움직일 것.
- RL 다리 액션: 다리 목표 = h_ref + 0.03 m × clamp(a, ±1). 바퀴: 1.5 Nm × clamp(a, ±1) 에 20 Hz LPF.

## 조이스틱 (Xbox, joydev 직접 읽기 — `sim/isaaclab/source/wheeled_biped_isaaclab/joystick_input.py`)

| 입력 | 동작 |
|---|---|
| 왼스틱 세로 | 전진/후진 (끝까지 = ±0.45 m/s) |
| 왼스틱 가로 | 제자리 회전 (끝까지 = ±1.0 rad/s) |
| 오른스틱 세로 | 높이 올리기/내리기 (속도 입력 — 놓으면 그 높이 유지) |
| A | 비상정지 (vx = wz = 0, 높이 유지) |
| B | 높이 기본값(182.5 mm 관절값 = h 242.5 mm) |

축 배치(고전 xpad / 최신 hid)를 자동 판별한다. 파일 하나로 ROS 노드에서도 그대로 쓸 수 있다
(표준 라이브러리만 사용). 패드가 끊기면 `connected=False` → 정지로 처리할 것.

## 참고

- VMC+LQR 을 먼저 쓴다면 같은 조이스틱 매핑으로 x_d/v_d, wz_d, h_d 를 만들면 된다.
- 측정 스크립트 `sim/isaaclab/scripts/measure6.py` 가 5방향 × 3높이 + 높이 전환을 잰다.
  실기에서도 같은 조건표로 재면 비교가 된다.
