# 데스크톱 → 로봇: 모터·IMU 로그 요청 (sim ↔ 실기 비교용)

사용자 요청으로 실기에서도 모터·IMU 로그를 남기도록 세팅해 달라.
데스크톱은 같은 채널을 시뮬에서 기록한다 (`sim/isaaclab/scripts/play_log.py`, 200 Hz).
채널을 맞춰 두면 같은 스크립트로 두 쪽을 겹쳐 볼 수 있다.

## 기록할 것

**모터 (4 축: 다리 L/R AK60-6, 바퀴 L/R AK45-10) — 받는 속도 그대로 (지금 50 Hz, 올리면 그 속도)**
- 타임스탬프 (수신 시각, 가능하면 드라이브 시각도)
- 위치 [rad], 속도 [rad/s], 전류 [A], 토크 추정 [Nm] (= 전류 × Kt, Kt 값도 같이 기록)
- 지령 (모드, 지령값) — 지령을 보낸 경우
- 온도, 에러 코드
- CAN 통계 (rx/tx 프레임 수, 에러 프레임) — 피드백 누락 확인용

**IMU (iAHRS) — 센서 최대 속도**
- 타임스탬프, 쿼터니언(또는 roll/pitch/yaw), 각속도 [rad/s], 가속도 [m/s²]
- 센서 원본 축 그대로 + `imu_link` 기준 변환값 (둘 다 — 축 매핑 검증용)

**제어기 (VMC+LQR 돌릴 때)**
- 상태 [θ, θ̇, x, ẋ], h, K(h), T_theta, T_delta, 바퀴별 토크 지령, 고관절 토크 지령, 클램프 여부

## 형식 제안

- `ros2 bag record` (mcap) 로 위 토픽 전부. 파일명에 날짜·시각·실험 이름.
- 한 번 기록할 때 **처음 5 초는 가만히** (영점·정적 기울기 트림 계산용 — 이전 메시지 4 절).
- 저장소에는 bag 원본을 넣지 말고(용량), 필요한 구간만 CSV 로 뽑아 `logs/` 같은 곳에 두거나
  경로만 `comms/to-desktop/` 로 알려 달라.

## 참고 — 시뮬 쪽에서 방금 찾은 것

RL 학습 때 액션 클리핑이 꺼져 있어서 (IsaacLab 기본 `clip_actions=None`) 정책이 바퀴를
모터 한계 7 Nm 로 10 Hz 뱅뱅, 다리는 하한에 붙여 버렸다. 로그로 잡았다. 수정 후 재학습 중.
실기는 VMC+LQR 로 가니 직접 영향은 없지만, **실기 제어기에서도 지령 클램프(바퀴 약 0.5~0.8 Nm)를
명시적으로 걸어 달라** — 스케일만으로는 한계가 안 된다는 교훈.
