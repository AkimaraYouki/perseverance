# 데스크톱 → 로봇: iAHRS RB-SDA-v1 설정 권장 + 시뮬 쪽 변경 (LPF)

사용자가 쓸 IMU 매뉴얼을 줬다 (`docs/vendor/IAHRS_manual_rb_sda_ob_v_dn_2.0.1_210607.pdf` 와 같은 파일).
제어·프레임에 걸리는 것만 뽑았다. 쪽수는 매뉴얼 인쇄 쪽 기준.

## 1. 축 — imu_link 와 맞추기 (매뉴얼 1.2.2, 3 쪽 그림)

- 오른손 좌표계. **Z = 라벨(윗면) 밖으로**, X·Y 는 윗면 평면.
- 그림상 **X 는 micro-USB 커넥터가 있는 면의 반대쪽**을 향한다. (등각 그림을 읽은 것이라 **케이스 윗면에 인쇄된 작은 축 표시를 최종 기준**으로 할 것.)
- CAD 의 `imu_link` 는 rpy = 0 (x 전진, y 왼쪽, z 위)이다. 그대로 쓰려면 **라벨이 위, USB 커넥터가 로봇 뒤쪽**을 보게 달아야 한다. 다르게 달면 알려 달라 — `imu_link` 회전을 바꾸겠다.
- 부호 확인법: 로봇을 **앞으로 기울였을 때 sensor pitch 가 증가**하면 LQR 의 θ 정의(앞으로 기울면 +)와 같다. 매뉴얼 Euler 는 Z-Y-X, pitch 는 ±90°.

## 2. 통신 설정 (출하 기본값으로는 제어에 못 쓴다)

| 항목 | 기본값 | 권장 | 이유 |
|---|---|---|---|
| `b2` USB baud | 115200 | **921600** | ASCII 출력이라 115200 이면 약 100 Hz 가 한계. "대역폭을 넘으면 주기가 안 지켜진다" (4.2.20) |
| `sp` sync 주기 | **100 ms (10 Hz)** | **2~5 ms** (500~200 Hz) | 기본 10 Hz 는 밸런싱 불가. LQR 게인은 200 Hz 로 검증함 |
| `sd` sync 데이터 | 0x000 | **0x008D** = 1ms 카운트(0x1) + 가속도(0x4) + 각속도(0x8) + 쿼터니언(0x80) | 필요한 것만. 카운트로 누락·지터 확인 |
| `gs` 자이로 범위 | 3 (2000 dps) | **1 (500 dps)** | 균형 중 pitch rate 는 수백 dps 이내, 분해능 4배 |
| `as` 가속도 범위 | 3 (16 g) | **2 (8 g)** | 계단 충격 여유는 남기고 분해능 향상 |
| `gl` 자이로 내장 LPF | 0 (196.6 Hz) | **3 (51.2 Hz)** 로 시작 | 200 Hz 제어에 충분한 대역, 모터 진동 억제. 지연 약 3 ms |
| `mv` 방위(지자기) 보정 | 0 (꺼짐) | **0 유지** | IMU 가 다리 모터에서 약 10 cm. 균형에는 yaw 불필요 |

변경 후 `fw` (플래시 저장) → `rd` (재시작) 해야 적용된다. 단위 주의: **각속도 deg/s, 가속도 g** → ROS 로 낼 때 rad/s, m/s² 로 변환.

## 3. 장착 위치와 가속 편향 — 제어기 설계에 중요

매뉴얼은 "회전중심/무게중심 근처에 달라, 아니면 구심가속도로 각도가 편향된다"고 한다.
이 로봇의 pitch 회전중심은 바퀴축이고 IMU 는 그보다 약 20~30 cm 위다. 피할 수 없다.

더 큰 문제는 **로봇이 가감속할 때**다. AHRS 는 roll/pitch 를 중력 방향으로 보정하는데,
전진 가속 a 가 있으면 겉보기 중력이 기울어 **pitch 가 약 atan(a/g) 만큼 편향**된다
(1 m/s² 이면 약 5.8°). 균형 제어에서 이 정도면 치명적이다.

→ 권장:
- θ̇ 는 **자이로 각속도(y)를 직접** 쓴다 (AHRS 추정각 미분 금지).
- θ 는 AHRS 쿼터니언을 쓰되, 가감속 중 편향이 보이면 자이로 적분 + 느린 가속도 보정의
  자체 상보필터로 바꾸거나, 바퀴 오도메트리 가속도로 보정한다. `av` (자세 보정 분산) 를 키우면
  가속도 신뢰를 줄일 수 있다.
- 첫 기동 로그(이전 메시지 요청)에 **가감속 구간의 pitch 와 자이로 적분값을 같이** 남겨 달라. 편향 크기를 재겠다.

## 4. 시뮬 쪽 변경 — 실기 제어기도 맞춰야 할 것

RL 정책 재생에서 바퀴가 약 10 Hz 로 떨렸다 (사용자 관찰, 로그로 확인). 원인과 수정:
- 원시 액션이 ±1 을 크게 넘어(최대 194) 바퀴 토크가 한계 사이를 뱅뱅. → 액션 항 안에서 ±1 로 자르고 범위 이탈에 벌점.
- **바퀴 토크 지령에 1차 LPF (fc 20 Hz, 200 Hz 에서 a = 0.466, 시정수 8 ms)** 를 넣었다
  (`sim/isaaclab/.../tasks/balance/actions.py`). **RL 정책을 실기에 올릴 때는 같은 필터를 같은 주기로
  넣어야 한다.** VMC+LQR 에도 넣을지는 실기 진동을 보고 판단 — 넣으면 알려 달라 (시뮬 검증을 맞추겠다).
- 보상 함수 버그 2 건 수정 (관절 선택이 전 관절로 잡혀 있었음). RL 결과는 재학습 중이고, 실기 VMC+LQR 과는 무관.
