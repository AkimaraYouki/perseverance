# 데스크톱 → 로봇: 높이 모드(자동/수동), 거친 지형 학습, 랩미팅 문서

## 1. 사용자 결정 (2026-09-25)

- **높이 모드 두 가지.**
  - 수동 = 사용자가 트리거로 높이를 정한다(지금 방식).
  - 자동 = 정책이 외란·지형을 보고 **양쪽 다리 높이를 스스로** 정한다. 몸통은 짐벌처럼 제자리에 둔다.
- **IDLE / 자동 공칭 높이 = CAD 기본자세**: M = 0°, θ 45.0°, 다리 관절값 h 136.5 mm (고관절 높이 196.5 mm).
- **다리 권한은 최소·최대 양끝까지**: 어떤 높이 기준에서든 122.5 ~ 242.5 mm 전 구간을 쓴다.

## 2. 정책 인터페이스 변경 (거친 지형 과제 `Isaac-WheeledBiped-CAD-Rough-v0`)

명령이 3 개에서 4 개로 늘었다: `c = [vx, wz, h_ref, m]`, m = 0 수동 / 1 자동. 관측은 19 → **20** 이다. m 이 인덱스 9 에 들어가고 그 뒤가 한 칸씩 밀린다.

| 인덱스 | 내용 |
|---|---|
| 0–2 | 자이로 [rad/s] |
| 3–5 | 투영 중력 |
| 6–9 | vx*, wz*, h_ref, **m** |
| 10–11 | 다리 h − 0.1825 (L, R) [m] |
| 12–13 | 다리 dh/dt (L, R) |
| 14–15 | 바퀴 각속도 (L, R, +y 규약) |
| 16–19 | 직전 행동 |

**다리 행동**:

```
h* = clip(h_ref + 0.12·clip(a, -1, 1), 0.1225, 0.2425)
```

예전 스케일은 0.03 이었다.

**자동 모드**에서는 h_ref 가 0.1365 (CAD 기본자세)로 고정되고, 트리거 입력은 무시한다.
h_ref 속도 제한(0.10 m/s)과 바퀴 LPF 20 Hz 는 그대로다. 식과 표는 `docs/lab-meeting/software/01_learning.md` §3–5 에 있다.

평지 과제(19 차원, 스케일 0.03)도 그대로 남아 있다. 실기 첫 정책은 둘 중 측정 결과가 좋은 쪽으로 정해서 따로 알리겠다.

## 3. 조종 매핑 추가

**X = 높이 모드 전환** (수동 ↔ 자동). 나머지는 그대로다: 왼스틱 세로 vx, 오른스틱 가로 wz, RT/LT 높이, A 비상정지, B 높이 기본값.

ROS 제안: `/cmd_vel` (linear.x, angular.z) + `/height_cmd` (`std_msgs/Float32`, 다리 관절값 h [m]) + `/height_mode` (`std_msgs/UInt8`, 0/1).
균형 프로세스는 이 넷을 받아서 클램프하고, 워치독이 끊기면 vx = wz = 0 으로 둔다. 이름을 바꾸고 싶으면 알려 달라.
