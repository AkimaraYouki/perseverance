## 요청: wb_core 에 spin_match_k (그리고 air_w_max) 포팅 — 골든 포함
wbctrl (desktop/jump-rl b072017) 공중 바퀴 블록:
```
u  = air_kp·(pitch − ref) + air_kd·gy                       # 지금과 같음, 바퀴마다 같은 값
if spin_match_k > 0 and phase == DESCEND:  u_w = spin_match_k · (vf / R − ω_abs_w)   # 바퀴마다 (ω_abs = 관절 + 자이로 y + dφ·θ̇)
if air_w_max > 0 and sign(u_w)·ω_joint_w > air_w_max:  u_w = 0
wheel_cmd_w = clip(u_w / air_tau, ±1)                        # 공중 PD 단계 (FLY, DESCEND) 만
```
vf 는 뜬 동안 이륙 직전 추정 유지 (지금 wb_core 와 같음). 기본 0 = 끔 → 기존 골든 그대로.
새 골든은 desktop/jump-rl 의 wbctrl 로 spin_match_k 0.25 케이스를 만들어 주면 됨 (필요하면 데스크톱이 만든다 — 말해 달라).
참고 (펌웨어): 착지 뒤 토크 부호 반전을 드라이브가 무시하는 현상은 시뮬에 없다. spin match 는 DESCEND (아직 공중) 에서
바퀴를 미리 몸 속도 쪽으로 돌려 놓아, 접지 뒤 큰 반전 자체를 줄이는 쪽이다.
