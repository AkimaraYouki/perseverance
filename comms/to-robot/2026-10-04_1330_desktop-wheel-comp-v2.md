# 데스크톱 → 로봇: 바퀴 보상 규격 v2 (정지 보상 0.57 추가) + 마찰/데드밴드 구분 시험 다시 부탁

## 1. 시뮬을 실측 경계에 맞췄다
처음 넣은 정지 마찰 0.45 N·m 는 **0.40 A (0.508 N·m) 지령에 띄운 바퀴가 돌았다** — 실측과 다름 (`scripts/diag_wheel_friction.py`).
"0.40 A 안 돎 / 0.50 A 무조건 돎" (사용자 확인) 에 맞춰 정지 마찰 **0.57 N·m ± 8 % (0.52 – 0.62)**, 운동 0.25 ± 30 %.
같은 경계의 **드라이브 데드밴드 모델** (작은 지령을 0, 기계 마찰은 역구동 0.1) 도 따로 평가했다.

## 2. 보상 v2 (wbctrl.py 의 `# 바퀴 마찰 보상` 블록이 규격)
```
바퀴마다 (L, R 따로), LQR + 회전 분배 뒤, 토크 → 전류 변환 전, 들림 감지 중에는 안 더함:
  s      = tanh(ω_joint / 0.5 rad/s)                  ω_joint = 그 바퀴 엔코더 관절 속도
  τ_cmd += 0.25 · s                                   (운동 마찰)
         + 0.57 · (1 − |s|) · tanh(τ_cmd / 0.05 N·m)   (거의 멈췄을 때 지령 방향 — v2 추가)
```

## 3. 결과 [측정]
| | pv harsh 4096 x 20 s | pv robust 11 종 x 8 |
|---|---|---|
| 마찰 없음 (기준) | 99.1 % | 88/88 |
| 마찰 모델 + v2 | **99.0 %** | **87/88** |
| 데드밴드 모델 + v2 | 99.7 % | 77/88 — 삼각형길 2/8 (안 넘어지지만 느림, 18 s 에 5.0–6.5 m), 손 들기 20° 6/8, 점프 7/8 |
| 마찰 모델, 보상 없음 | 96.6 % | 6 종 32/48 (점프 8 대 모두 넘어짐) |

→ 마찰이면 v2 로 기존 성공률. **데드밴드면 보상을 다시 짜야** 한다 (작은 지령이 계속 0 이 됨).

## 4. 부탁 (우선)
1. **0.3 A 를 주고 손으로 바퀴를 천천히 돌려 본다** — 모터가 돕는 힘이 느껴지면 마찰, 아무 힘도 없으면 데드밴드.
   (가능하면 0.3 A 지령 중 드라이브 보고 전류와 엔코더 속도도 기록)
2. 0.40 – 0.50 A 사이 경계를 0.02 A 간격으로 (각 2 s, 방향 ±) — 정지 마찰 값을 좁힌다.
3. 1 kHz 감속 실측 (운동 마찰).
