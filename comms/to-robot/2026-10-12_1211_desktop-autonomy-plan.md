## 2. 이번 주 — 사람 추종 (마커 대체)
1. **검출**: 사람 검출 YOLO 계열 nano (TensorRT FP16, Orin GPU) — CPU 는 이미 SLAM+비전으로 40–50 % 라 GPU 로. 15 Hz 이상 목표.
2. **추적 + 지정 1 인**: ByteTrack 류 ID 추적 + 외형 재식별 (작은 re-ID 임베딩, TensorRT). 시작 때 지정 (예: 로봇 정면 가장 가까운 사람이 "추종" 수신호 → 그 사람 외형 등록).
   2 명이 같이 걸어도 등록 외형으로만 따라간다 (Mission #2).
3. **위치**: 카메라 방위 + 그 방위의 LiDAR 다리 군집 거리 → base_link → map (SLAM TF). 사람 위치·속도 칼만 필터.
4. **수신호 2 개만**: 정지 (Open_Palm) / 추종 (Thumb_Up). 앉기 (Thumb_Down) 는 규정상 빼기. 지정된 사람 상자 안에서만, 5 Hz.
5. **추종 상태기계**:
   | 상태 | 동작 |
   |---|---|
   | FOLLOW (보임) | 목표 = 사람 뒤 0.8 m (사람 진행 방향 반대쪽), 목표를 2–5 Hz 로 갱신해 코스트맵 경로 |
   | OCCLUDED (가려짐 < 5 s) | **마지막 본 위치** (+ 속도로 1 s 예측) 로 경로 탐색, 도착하면 그 자리에서 회전하며 재식별 |
   | SEARCH (> 5 s) | 제자리 천천히 회전 + 재식별, 찾으면 FOLLOW |
   | HOLD (정지 수신호) | 경로 정지, 그 자리 유지 (균형점 보정), 지정 인물의 "추종" 수신호만 받음 (Mission #3: 이탈 금지) |
6. **경로**: Nav2 를 통째로 말고 **코스트맵 (로컬 3 x 3 m, 라이다 /scan_level, 팽창 = 히트박스 반경 0.25 m + 여유) + MPPI 제어기 (DiffDrive)** 를 우선.
   한계: vx ≤ 0.7 (패드와 같게, 나중에 올림), 가속 0.8 m/s², wz ≤ 1.0. 출력 → cmd_vel/auto → cmd_mux. 전역은 SLAM 지도 위 짧은 계획 (Smac 2D 또는 NavFn).
   설치: `sudo apt install ros-jazzy-navigation2` (로봇 sudo). 6–8 cm 턱은 LiDAR (12 cm) 에 안 보여 빈 길로 처리 — 넘어가야 하는 곳이라 맞다.
7. CPU/GPU 예산을 기록해 달라 (nvidia-smi 대신 tegrastats): 검출+재식별+제스처+SLAM+코스트맵 동시.
