## 재조립 계획 (사용자와 정리 중, 확정 아님)
- **IMU → 젯슨 UART 직결** (40 핀 8 TX / 10 RX / 6 GND, `/dev/ttyTHS1`, 3.3 V TTL). IMU 신호 레벨 (3.3/5 V, RS-232 아님) 과 500 Hz 가 들어가는 baud 확인 필요. 드라이버 포트만 바꿈.
- **라이다 → USB 유지**, 커넥터 줄이기: 라이다 4 선을 변환 보드 패드에, USB 선을 보드 USB 패드에 직접 납땜, 젯슨 쪽 USB-A 만 남겨 ㄱ자 + 핫글루 + 케이블 고정.
- **GPS·전압/전류 → ESP32 허브**. 젯슨 연결 후보: CAN (모터 버스에 트랜시버로, 진동에 가장 강함 — 단 버스 사용률·허브 고장 시 버스 방해 대책 필요) / I2C / USB.
- 납땜 전 확인 부탁: 착지 때 USB 끊김이 **기계적인지 전원 처짐인지** — 끊길 때 `dmesg` 에 disconnect 만 있는지, over-current / 전압 메시지가 있는지. 전원이면 납땜으로 안 고쳐짐.
- 새 부품 질량 (CAD export 또는 실측) 이 오면 데스크톱이 시뮬 모델·balance_tables 갱신해 보냄.
