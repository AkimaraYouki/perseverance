# 데스크톱 → 로봇: 0.5 A 경계가 "마찰"인지 "드라이브 데드밴드"인지 가리는 시험

## 사용자 실측 (CubeMars 제어, 2026-10-04)
- **0.5 A 미만은 안 돌고, 0.5 A 이상일 때만 돈다.**
- 돌 때 실제 소모 전류는 **약 0.1 A** → 운동 마찰 ≈ 0.1 × 1.27 = **0.13 N·m** (전원 쪽 전류라 해도 ≤ 0.14 N·m).
- 시뮬 반영: 경계 0.625 N·m ±1 %, 운동 마찰 0.25 → 0.13, 보상 = 속도 방향 0.13 + 멈췄을 때 지령 방향 0.625 (재평가 중).

출발에는 0.635 N·m 가 필요한데 돌 때는 0.13 N·m 면 된다. 원인이 둘 중 하나다 — 균형 제어에 미치는 영향이 완전히 다르다.
| | 정지 마찰·코깅 | 드라이브 데드밴드 (작은 지령 무시) |
|---|---|---|
| **이미 도는 중** 0.5 A 미만 지령 | 0.13 N·m 만 이기면 **계속 돎** | 토크 0 → **0 A 때처럼 서서히 멈춤** |
| 균형 제어 | 출발 순간만 걸림 → 지금 보상으로 됨 | 0.5 A 미만의 작은 보정이 늘 사라짐 → 보상을 다시 짜야 함 |

## 시험 1 — 돌다가 지령 낮추기 (결정적)
바퀴를 띄우고, 엔코더 속도를 **200 Hz 이상 (가능하면 1 kHz)** 로 기록하면서:
1. 0.5 A 로 2 s 돌린다 (정상 속도까지).
2. 멈추지 않은 채 지령을 바꿔 3 s 유지: **0.3 A**, **0.2 A**, **0.1 A**, **0 A** — 각각 따로 (매번 1 부터).
3. 양방향 (±) 모두.

보고: 지령별 3 s 동안의 속도 곡선 (또는 최종 속도·멈춘 시각), 드라이브 보고 전류.
판정: 0.3 A·0.2 A 에서 **계속 돌면 마찰/코깅**, 0 A 와 **같은 곡선으로 멈추면 데드밴드**.
(0 A 곡선의 감속도 = 운동 마찰 / 관성 — 1 kHz 감속 실측 요청도 이걸로 겸한다.)

## 시험 2 — 멈춘 바퀴를 손으로 (보조)
0.3 A 지령 중에 손으로 바퀴를 지령 방향으로 천천히 돌려 본다. 모터가 미는 힘이 느껴지면 마찰/코깅, 아무 힘도 없으면 데드밴드.

## 시험 3 — 경계 좁히기
멈춘 상태에서 0.40 → 0.50 A 를 0.02 A 간격, 각 2 s, ± 방향. 처음 돈 전류 (위치에 따라 다르면 코깅 — 바퀴를 조금씩 돌려 놓고 3 위치에서).
