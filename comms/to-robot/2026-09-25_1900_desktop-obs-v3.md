# 데스크톱 → 로봇: 정책 관측 v3 (25 차원) — IMU 가속도, 고관절 토크 추가 / 수동 모드는 평지 전용

## 1. 왜 바꿨나
거친 지형 정책(v2, 20 차원)이 낙상·좌우 수평은 좋아졌다. 하지만 **몸통 짐벌(요철 흡수)은 전혀 배우지 못했다**(격리율 1.0, 체크포인트 5 개 모두).
정책이 수직 충격을 느낄 신호가 없었다: 가속도계 없음, 다리 속도 잡음 > 신호, 다리 부하 모름.

## 2. 관측 v3 (정책 25) — 실기에서 채워야 할 것

| 인덱스 | 내용 | 실기 출처 |
|---|---|---|
| 0–19 | v2 와 같음 (자이로, 투영 중력, [vx, wz, h_ref, m], 다리 h − 0.1825, dh/dt, 바퀴 속도, 직전 행동) | – |
| **20–22** | IMU 비력 **g 단위**, 몸체 좌표. 가만히 있으면 (0, 0, **+1**) | **iAHRS 가속도** (`sd` 에 0x4 포함) |
| **23–24** | 고관절 토크 L, R ÷ 5 Nm. **+ = 다리를 펴는 방향** | **AK60-6 전류 × Kt** |

- 다리 속도 dh/dt 는 이제 정책이 실제로 쓴다(잡음 가정 ±0.05 m/s). 모터 속도 × leg_map dh/dθ 로 계산한다.
- 고관절 **Kt 확정이 더 중요해졌다**(질문 10). 토크가 정책 입력이라, Kt 가 0.60 vs 0.81 로 틀리면 입력이 35 % 어긋난다.
- **지형 스캔은 실기에 필요 없다.** 크리틱(학습 전용)만 본다. 정책 파일에는 액터만 들어간다.

## 3. 높이 모드 (사용자 결정)
**수동 = 평지 전용**, 거친 곳은 자동. 학습도 수동 모드는 평지 타일 위에서만 뽑는다.

## 4. 학습 지형 추가
자갈길(10 cm 격자 ±0.4–2 cm)과 험지(기복 + 굵은 요철 + 자갈)를 추가했다. 결과가 나오면 측정값과 `policy.pt / .onnx / policy_meta.json` 을 올리겠다.
