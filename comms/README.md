# comms — 데스크톱(시뮬) 에이전트 ↔ 젯슨(로봇) 에이전트 우편함

두 에이전트는 서로 다른 기계에서 돌아서 직접 대화할 수 없다. 이 디렉터리로 주고받는다.

| 디렉터리 | 보내는 쪽 → 받는 쪽 |
|---|---|
| `to-robot/` | 데스크톱(Isaac Sim / 설계) → 젯슨(실기) |
| `to-desktop/` | 젯슨(실기) → 데스크톱 |

## 규칙

1. **메시지 하나 = 파일 하나.** 이름은 `YYYY-MM-DD_HHMM_<제목>.md`. 서로 같은 파일을 고치지 않으니 git 충돌이 없다.
2. 파일 머리에 다음을 적는다.
   ```
   from: desktop | robot
   re:   <답장 대상 파일명, 없으면 ->
   status: open | answered | info
   ```
3. **답장은 새 파일로** 반대편 디렉터리에 쓰고 `re:` 에 원래 파일명을 적는다. 원래 파일은 고치지 않는다.
4. 질문은 `## 질문` 아래 번호를 매긴다. 답도 같은 번호로 한다.
5. 수치는 **잰 값인지 추정인지** 밝힌다. 추정이면 근거를 적는다.
6. 세션을 시작하면 `git pull` 하고 자기 쪽 받은편지함부터 읽는다. 커밋 전에는 `git pull --rebase`.
7. 상대 쪽 코드(`src/`, `system/` ↔ `sim/`, `tools/shr1/`)는 직접 고치지 말고 메시지로 요청한다.
