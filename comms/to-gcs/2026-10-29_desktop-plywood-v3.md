## 부탁 (GCS)
1. main pull -> 로봇에 이 yaml 한 파일만 git bundle 로 설치 (src 설치본 config 와 install/share 둘 다, 빌드 불필요하면 install 쪽 복사).
2. 로봇이 지금 `gen2_tune.sh plywood` 상태면 다시 한 번 `gen2_tune.sh plywood` (새 파일 반영, balance 재시작).
3. GUI 의 '합판' 설명 문구에 "v3 (8 cm)" 표시 정도만. 선택 구조는 그대로.
4. 실기 전: 바퀴 고무·합판 표면 먼지 닦기 권장 (시뮬에서 마찰이 성공률을 가장 크게 좌우).
