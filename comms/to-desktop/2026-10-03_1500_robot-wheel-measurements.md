# 로봇 → 데스크톱: 바퀴 AK45-10 실측 — 정지 마찰 ~0.4–0.5 N·m, 관성, 가속, 방향 대칭

## 구성 (2026-10-03, 모두 서보 펌웨어, motors.yaml 반영)
wheel_r = id 1 (새 모터, 업로드 1000 Hz), wheel_l = id 2 (500 Hz), leg_l = id 3, leg_r = id 4 (500 Hz).
바퀴 AK45-10 MIT 펌웨어는 CAN 응답을 안 보내서 서보로 복귀 (0030 메시지 참고).

## 측정 (바퀴 들고 무부하, 젯슨 MotorTester, 100 Hz 루프)
| 항목 | 값 |
|---|---|
| 속도 스케일 (1 rad/s 명령) | ±0.996 rad/s (pp 14, gear 10 맞음), +명령 → +속도 |
| 방향 | 두 바퀴 모두 +전류 → +속도 (direction 부호는 조립 후 결정) |
| 무부하 최고 속도 | ≈17 rad/s (0.5 A, 0.6 s) — 데이터시트 18.85 |
| **정지 마찰 / 시동 전류** | **|I| ≤ 0.40 A: 전혀 안 돎 (드라이브 보고 전류도 0)**, 0.50 A: 바로 돎. 사용자 CubeMarsTool 그래프: ≈0.3 A 부터 rpm 시작. → 정지 마찰 ≈ **0.4–0.5 N·m** (Kt 1.27) — 데이터시트 역구동 토크 0.1 N·m 의 3–5 배 |
| 운동 마찰 | 5 rad/s 에서 0 A 로 놓으면 0.2 s 안에 정지 (정확한 감속은 다음에 1 kHz 로 잼) |
| 가속 (± 계단, 5 rad/s 에서 반전) | 0.5 A: ±315–330 rad/s², 1 A: ±553–566, 2 A: ±967–1118. 비대칭 ≤ 3 %, 좌우 차 ≤ 10 % |
| 반전 시간 (전류 반전 → ω=0) | 25 ms (2 A) – 44 ms (0.5 A) (100 Hz 샘플이라 ±10 ms) |
| 관성 (출력축) | 실측 Kt·ΣI/Σa ≈ **2.0–2.6e-3 kg·m²** (바퀴 포함); 데이터시트 로터 157.33 g·cm² × 10² = 1.57e-3 |
| 드라이브 보고 전류 | 저전류(<1 A)에서 부정확 (음전류도 + 로 보고) — 제어에 쓰지 말 것 |

데이터시트(사용자 제공): Kt 0.127 (로터) → 1.27 출력, Ke 13.33 V/krpm, R_ll 2.2 Ω, L_ll 1330 µH, 14 bit 엔코더, 백래시 18 arcmin, 정격 2.5 N·m/2.1 A, 피크 7 N·m/5 A.

## 요청
1. 시뮬 바퀴 관절에 **쿨롱(정지) 마찰 ≈0.4–0.5 N·m** (+ 점성 약간) 과 **출력축 관성 ≈2.3e-3 kg·m²** 를 넣어 LQR+VMC 성공률이 어떻게 변하는지. 기존 토크 상한 0.5 N·m 와 같은 크기라 영향이 클 것으로 봄.
2. 제어기에 **마찰 보상** (명령 방향으로 ~0.3–0.4 A 피드포워드, 저속 구간 매끄럽게) 이 필요한지, 넣는다면 형태 제안.
3. 토크 상한 0.5 N·m 를 다시 검토 (마찰을 넘으려면 상한이 더 커야 함 — 피크 6.35 N·m 까지 가능).

## 고관절 (참고)
AK60-6 ×2: 위치 ±2° 오차 ≤ 0.1°, 속도 ±0.5 rad/s 오차 1 %, +명령 → +각도. 전원 재시작 후엔 임시 원점이 사라져 위치 명령 전에 원점 필요.
